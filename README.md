# Crypto Trading Agent v2

Агент помогает разобрать рынок и конкретную монету. В отчёте по монете (Coin Profile) видно, что подтверждают данные, где источники расходятся и при каких условиях вывод изменится. Если сценарий и данные позволяют, агент подготовит черновик настроек для Veles или GinArea.

Текущий режим — анализ синтетических данных и сохранённых исторических срезов (`SYNTHETIC_ONLY / NO_TRADE_READY`). Подключение реального счёта, размещение ордеров и запуск ботов требуют отдельной приёмки.

## Быстрый старт

1. Открой в Codex Cloud новый сеанс с доступом к репозиторию `vbondarev/crypto-trading-agent`. Выбери [ветку v2](https://github.com/vbondarev/crypto-trading-agent/tree/feature/simplified-agent-v2) до слияния или `main` после него.
2. Отправь запрос ниже. Он использует синтетический пример из репозитория.

> Прочитай `AGENTS.md` из выбранной ветки. Открой пример HYPEUSDT в `tests/v2/fixtures/incomplete-hype.v1.json`. Объясни, почему в нём решение WAIT (подождать) и каких данных не хватает, чтобы оценить вход в позицию.

## Анализ своих данных

Приложи синтетические данные или сохранённый исторический срез с датой, временем и часовым поясом. Укажи монету, биржу, тип рынка и горизонт. Подставь свои параметры в запрос ниже.

> Прочитай `AGENTS.md` из выбранной ветки. По приложенному срезу оцени HYPEUSDT на Bybit USDT Perpetual на ближайшие 1–3 дня от момента среза. Объясни, что видно по тренду, какой сценарий лучше поддерживают данные (LONG, SHORT или WAIT) и что может изменить вывод.

Если нужен черновик бота, дополни запрос, указав платформу и режим.

> Если данных достаточно, покажи черновик для Veles SIMPLE и перечисли поля, которые ещё нужно подтвердить.

Не публикуй в репозитории API-ключи, пароли, снимки счёта и реальные торговые отчёты.

Для разработки и проверок v2 используй Python. Команды выполняются из корня репозитория.

python tests/v2/workflow_smoke.py
