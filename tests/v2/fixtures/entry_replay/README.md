# Проверка решения по фиксированному срезу

Из корня проекта выполни для каждого идентификатора A–D команду
`python tests/v2/fixtures/entry_replay/build.py A ../p0-input-A`, подставляя
один идентификатор в оба аргумента. Скрипт строит четыре согласованных
интервала из одного синтетического ряда. Для каждого случая открой отдельный
новый чат. Передай только запрос ниже и его каталог CSV. Таблица оценки
предназначена проверяющему после получения первого ответа.

## Запрос

Выполни эталонный промт docs/prompts/reference-market-analysis.md из рабочей копии проекта, используя её HEAD и текущие правки инструкций. Это воспроизведение на синтетическом фиксированном срезе. Источники — только переданные условия и четыре CSV в ../p0-input-<ID> относительно корня проекта. Используй штатный калькулятор. As-of 2026-11-20T12:15:01Z. Тестовая спецификация HYPEUSDT Bybit LinearPerpetual, Trading, USDT. По условиям среза BTC и ETH нейтральны, событий и блокирующих факторов нет, цены внешних рынков и деривативные ряды не предоставлены. Единственное правило входа: по последней ожидаемой закрытой 15м свече Close строго выше 101 даёт покупку, строго ниже 99 даёт продажу. До следующего закрытия оцени именно этот сигнал. Платформа VELES, режим CUSTOM, учебный бюджет 100 USDT, доступная маржа 200 USDT на момент среза, портфель не предоставлен. Верни компактный полный отчёт. Для независимой проверки читай только свой каталог входов и документы/калькулятор проекта, исключи остальные тестовые материалы и историю чатов. Файлы не меняй.

## Критерии первого ответа

| Вход | Решение | Покрытие правила | Основание | Следующее действие | Черновик |
|---|---|---|---|---|---|
| A | LONG | COMPLETE_FOR_SCOPE | 102 > 101 | Пересмотреть по следующему закрытию | NEEDS_DATA |
| B | SHORT | COMPLETE_FOR_SCOPE | 98 < 99 | Пересмотреть по следующему закрытию | NEEDS_DATA |
| C | WAIT | COMPLETE_FOR_SCOPE | 100 внутри диапазона | Проверить выход за 99–101 на закрытии 12:30 UTC | NOT_RECOMMENDED |
| D | WAIT | INSUFFICIENT | Отсутствует 15м свеча HYPEUSDT с закрытием 12:15 UTC | Восстановить именно эту свечу и повторить оценку | NOT_RECOMMENDED |

Во всех случаях проверь отдельный риск `NOT_EVALUABLE`, отсутствие числовой
сетки и различие между покрытием правила и общего рыночного фона. При D
предыдущая свеча остаётся доступной. Подстановка её Close вместо пропущенного
закрытия считается ошибкой. Сверь исполнение калькулятора по журналу чата.
