## 2. Реализованная структура Skill и нормативы

**Третий уровень проверок:** каждое предложенное поле Veles должно быть допустимо в документальном каталоге VL01–VL25 **и** присутствовать в текущей форме P02 для R3. `VL-23..VL-25` относятся к превью, тестированию и кнопке сохранения, **не к настройкам торгового ордера**. Формы `new_bot`, `edit_bot`, `running_trade` имеют разную семантику. Veles `Тип торговли` = Long/Short, `Режим торговли` = SIMPLE/CUSTOM/SIGNAL, `Тип маржи` = Cross/Isolated; биржевой One-Way/Hedge дополнительно проверяется на Bybit.

| Область | Что закреплено | Условие/запрет |
|---|---|---|
| **Выбор** | Сам пользователь выбирает Veles, стратегию и пару | Нет P02 — только R2 документальный черновик, не финальный конфиг |
| **Сетка** | Deposit, leverage, coverage, orders count, % martingale, log distribution, partial placement, pull-up | Не смешивать `Депозит` с первой IN/Equity, `Перекрытие` с шагом GinArea |
| **SIMPLE/CUSTOM/SIGNAL** | Разные способы построения IN, ручные доли vs сигнальные уровни | Нельзя брать одну формулу/одни единицы для всех |
| **POSITION −1** | Подхват реальной биржевой позиции | Не новый orderId, не второй слот, не новая прибыль H01 |
| **TP** | Simple от средней, custom multi-TP, signal и условный BE | Старый TP не обязательно уже снят, BE нетто не гарантирует |
| **Ordinary SL** | Процентный стоп после **последнего заполненного IN** | Нельзя считать SL уже стоящим до полной сетки; ликвидация может наступить раньше |
| **Signal SL** | Разный базис: **последний IN** vs **средняя цена** | От средней может сработать раньше полного IN при условии сигнала; стоп не гарантирует цену исполнения |
| **TP trailing** | В перечне просмотренной справки Bybit не указан | Не добавлять в Bybit P02 как доказанное поле, `NOT_VERIFIED` пока не подтверждено |
| **Бот lifecycle** | `Остановить` / `Отменить сделку` / `Закрыть по рынку` / `Перезапустить сделку` | Разное поведение; при Cancel фьючерсная позиция **остаётся открытой** |
| **Весь риск** | S0–S3, full T02, 100% будущего IN, FR-029..040, H01, Cross/MMR, Short bound и F/A/H/R | RV-02/03, RV-04/06, TV-01..04, real FR-038 остаются открыты; нет READY |

**Ложные эквиваленты запрещены:** Veles `% Мартингейла` ≠ GinArea `Мультипликатор`; Veles `Депозит` ≠ GinArea `Размер ордера`; Veles `Перекрытие изменения цены` ≠ GinArea `Шаг сетки`; Veles Stop/Pull-up ≠ GinArea Disable IN. Исторический H02/H03 без достоверного ряда остаётся `NOT_CHECKED`, но известная активная H04 блокировка запрещает NEW/ADD/restart, увеличивающий риск.
