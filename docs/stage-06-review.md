### 5.1. Критичные отрицательные выводы

- Для Bybit Cross / Portfolio Margin actual liquidation вызывается **account MMR≥100%**, а `position.liqPrice` — динамическая оценка; **15% adverse Mark** не доказать исключительно этим числом.
- **Veles обычный SL** выставляется после последнего IN сетки; ранняя ликвидация и худшее исполнение остаются возможными, даже при заполненном поле.
- **GinArea Default/Hedge** — документальное исключение; non-Default требует One-Way по официальной инструкции, а Bybit — UTA/Cross для описанного способа настройки; **это не проверка личного кабинета**.
- **Границы, Disable IN, Pause и «Отменить сделку» не равны нулевой биржевой позиции.**
- **H02/H03** (необязательная история Equity) при отсутствии `NOT_CHECKED`; **историческая Mark-история для протокола H FR-038 — отдельное обязательное доказательство**, которого нет. Известный **H04** блокирует увеличение риска.
