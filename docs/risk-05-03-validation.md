# Испытания шага 05.3 — Isolated Long/Short и FR-032

> **Статус: 05.3 `IMPLEMENTED / PENDING USER REVIEW` (15.10.2026).** Этот протокол относится к [`6–`7 методики](risk-management.md#6-ликвидация-isolated-margin-long-и-short-053). **Не является** подтверждением реальной liquidation price счета пользователя, валидированной Cross-модели или торговой готовности. Проверялись только открытая документация Bybit и детерминированные синтетические числа/логические предикаты.

## 1. Методика и первичные источники

Проверена актуальная официальная [UTA Liquidation Process](https://www.bybit.com/en/help-center/article/UTA-Trading-Rules-Liquidation-Process), **обновление 07.08.2026**, включая формулы Long/Short для USDT Perpetual и пример Long с дополнительной маржой. Сверена [New Margin Calculation](https://www.bybit.com/en/help-center/article/Understanding-the-Adjustment-and-Impact-of-the-New-Margin-Calculation) (18.06.2026): изменение базиса MM в Isolated и динамические ступени от Mark; [V5 Position Info](https://bybit-exchange.github.io/docs/v5/position), [V5 Get Risk Limit](https://bybit-exchange.github.io/docs/v5/market/risk-limit), [AMR](https://www.bybit.com/en/help-center/article/Auto-Margin-Replenishment). Приватный Bybit API **не вызывался**. Старые формулы 2024 года не являются эталоном.

Для арифметических проверок применена десятичная арифметика **Python Decimal, precision=36**, входы представлены точными десятичными строками; для проверок приблизительных значений использован абсолютный допуск **1e-7** в соответствующей единице (USDT/base либо процентный пункт), для логики/граничных значений — точное сравнение. *Это среда механического расчёта, а не исполняемый модуль MVP.* Не проверялись реальные округления до биржевого tick, частичные ликвидации и все варианты риск-ступеней/комиссий.

## 3. Нормативные сценарии и их статус

В [`7.2 методики](risk-management.md#72-нормативные-сценарии-l01l24) описаны **24 случая L01–L24**, включая отсутствующую/конфликтующую Mark, неподтверждённый MMR/deduction/taker fee, пустой API liqPrice, AMR, Hedge и статус при 14.999%. **Это 24 эталонных ожидания; независимые вызовы проверяемого ChatGPT по ним НЕ проводились.** Часть числовой логики отдельно подтверждена тестами T01–T28 выше.

### Ограничения проверяемости и оставшиеся зависимости

- **Риск-ступени динамичны:** в вычислениях T19–T21 дано специально заданное искусственное разбиение и проверка, что корень первой ступени выходит за её диапазон. Это **не** доказательство корректности пересчёта ступеней реальных инструментов. Для реального FR-032 нужны актуальные таблицы, их границы, MM deduction и связанные позиции/ордера по Mark.
- **Фактический isolated margin balance, funding, AMR и комиссии** не прочитаны из пользовательского счёта. Ни один пример не устанавливает их равными нулю при реальной операции; риск перекалибровки Mark/изменения T02 сохраняется.
- **FR-032 локально:** вычисленная по подтверждённым предпосылкам граница не закрывает FR-030 максимального убытка, FR-029/034 портфеля, FR-038 стрессов, P01/P02 и обязательный итог FR-040.
- **RV-02/TV-02 открыты:** Cross (05.4) не моделировался. **RV-03** (предельный убыток Short, 05.5) не закрыт. **TV-01/TV-03/TV-04** и RV-04/RV-06 сохраняются. Доказанный дефект плеча 50× или расстояния менее 15% сохраняет приоритет REJECTED.
