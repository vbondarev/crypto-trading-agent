## 2. Что реально добавлено

**Skill:** `risk-assessment/SKILL.md`, базовый YAML frontmatter (`name`, `description`), разделы `When to use / When not to use`, 13 основных относительных ссылок к утверждённым документам и соседним Skills, правила действительности входов, приоритетов и вывода. Отдельный полный YAML/spec-validator **не запускался**, только простая лексическая проверка текста в локальном тесте.

**Матрица покрываемых требований:**

| Блок | Подтверждённое инструкциями поведение | Недоказанное исполнение |
|---|---|---|
| FR-027–FR-028 | Нельзя смягчать строгие лимиты; вся текущая Equity и портфель, H02 DD ≤15% условно | Реальное Equity/FX/HWM неизвестны |
| FR-029 | IM всего портфеля **≤30% E0**, максимум по достижимым S0/S1/S2, избегать двойного счёта | Bybit tier/order IM/FX не верифицированы |
| FR-030 | Полная ожидаемая верхняя граница убытка бота **≤5% E0**, `L_from_now` и `L_lifecycle`, исполнение стопа/fee/funding | Строгая реальная Short bound **RV-03 OPEN** |
| FR-031–FR-034 | ≤5× leverage, ≥15% adverse Mark до ликвидации, ≤3 текущих/будущих слота, 100% future IN IM + буферы | Cross/MMR RV-02, будущая конкретная сетка и P02 |
| FR-035–FR-036 | Moscow 00:00, известный дневной 3%/HWM 15% блок, H02/H03 условны, **известный H04 не игнорировать** | Фактическая дневная Equity/денежные потоки/H04 пользователя неизвестны |
| FR-037–FR-038 | Co-loss/концентрация/корреляция, четыре **F/A/H/R** стресс-протокола для полного портфеля | Нет исторической реальной серии Bybit Mark, ликвидности, real F/A/H/R |
| FR-039–FR-040 | При нарушении WAIT/REDUCE/CLOSE или запрет IN, строгое `REJECTED > UNVERIFIED > NEEDS_DATA`; не выдавать READY по частной проверке | Конфигурационная финальная цепочка с P02 не исполнена |

**Точки риска, которые нельзя перепутать:** H02/H03 — *условная историческая Equity* (их отсутствие `NOT_CHECKED` не автоматический запрет), H04 — *подтверждённая активная блокировка* и строгий veto. Реальная история **цен Mark** для исторического стресса H — **обязательная**, даже если истории Equity H02/H03 нет. R3 требует свежих синхронных T02/Mark и реальной P02 выбранной платформы; Risk Skill сам не создаёт эти входы и не запускает позиции.

## 3. Фактически выполненные локальные тесты RA01–RA91

В [JS-файле](../tests/stage-07-05-risk-assessment-synthetic.mjs) приведены чистые учебные функции проверки порогов `marginGate/leverageGate/slotsGate/reserveGate/liquidationGate/botLossGate/equityDD/dayLoss/hBlock/validStress/inputGate` и иные вспомогательные модели, плюс **91 заранее заданное тестовое ожидание**. Сохранённый код извлечён из GitHub и исполнен в изолированном JavaScript/V8 с подстановкой фактического тела Skill; ссылки проверялись по изменённым файлам того же GitHub PR. На финальном прогоне **91/91 PASS, 0 FAIL**.

Первый прогон показал **90/91** из-за технического отличия `-0` от `0` при `Object.is` в тесте равной Long/Short-синтетики; тест нормализован, логика ограничений не менялась. После исправления был заново прочитан и запущен сохранённый файл — **91/91**. Отдельный `node` в клоне/CI, полноценный Bybit risk engine, другой ChatGPT blind-run и независимые тесты обнаружения Skills **не выполнялись**.

| Покрытие | Исполненные примеры и предел проверки |
|---|---|
| Metadata и FR | Проверка обязательных разделов, триггеров, FR-027–040 |
| Маржа/плечо/слоты/резерв | 30%, 5×, 3 позиции, 100% future IN, пример IM 250−40+42+38, сравнение E0 и E_s |
| Ликвидация / bot loss | Long/Short Mark100 и LP85/115, отдельная Cross модель, 5%-ная условная верхняя граница |
| H02/H03/H04 | DD=14.9/15/15.1%, Moscow midnight, дневные 2.9/3/3.4%, депозиты и выводы, известная H04 |
| F/A/H/R | Четыре *служебных признака* семейства, тест на фиктивную историческую H, отсутствие volatility/liquidity/threshold |
| R3, co-loss и вывод | T02 ≤5m, Mark ≤2m, P02, event invalidation, корреляция 30 наблюдений, reverse threshold и приоритет отказа |
| Ссылки | Документированные источники и существующие соседние Skills |

**Критический смысл:** локальные `F/A/H/R` тесты проверяют **правила принятия/отклонения доказательств** на вымышленных флагах, а **не выполняют стресс-тестирование реальной биржи**. Даже `FAMILIES_EVIDENCED_NOT_READY` — синтетическая служебная метка. Никакого вычисленного реального Cross account MMR или Short upper bound, никакого торгового READY нет.

## 6. Незакрытые риски, предлагаемый вердикт

- **RV-02:** реальный Cross account-wide MMR/liquidation и динамический tier не рассчитаны и не подтверждены. Показанная Bybit `liqPrice` не является достаточным доказательством соблюдения FR-032.

- **RV-04/RV-06 и TV-01–TV-04:** реальная P02, private T02, внешний/независимый trial, доступность фактических источников остаются открытыми.
- **FR-038:** реальные F/A/H/R по синхронизированным историческим Bybit Mark и полной маржинальной модели **не выполнены**.
- **Runtime:** полноценный spec-validator, ChatGPT auto-discovery/исполнение, CI и независимые blind-run не проверялись.
