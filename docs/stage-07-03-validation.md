## 2. Созданный Skill: область и границы

**Файл:** `.agents/skills/market-analysis/SKILL.md`, простая YAML-frontmatter `name: market-analysis`, `description`, явные `When to use` / `When not to use`, **11 внутренних относительных ссылок** на Data Verification Skill/принятую документацию и 4 ссылки на справки Bybit. Настоящее чтение файла из GitHub подтверждено при тестировании, автоматическая установка и загрузка Skill в ChatGPT — **не подтверждены**.

| Ветка | Поддерживаемая задача | Недопустимое расширение |
|---|---|---|
| **R1** | BTC/альткоины, общий тренд и источники с указанными датами; информационный/исторический контекст | Не требовать T02/личный портфель для справочного вопроса; не выдавать R1 за live R3 |
| **R2** | Проверенные закрытые OHLCV 15m/1h/4h/1d по необходимости, EMA/SMA/RSI/ATR, уровни, объёмы, OI/funding, события, базовая/альтернативная гипотеза | Без закрытой серии и методов не вычислять числовые индикаторы и уровни; не выдавать готовый вход/бот |
| **R3** | Передать свежие доказательства рынков в отдельную сверку Data Verification → Portfolio → Risk → выбранную платформу | Сам Skill не считает Cross/MMR и upper Short-loss, не проверяет весь T02, не заполняет P02 и **никогда не присваивает READY** |

**Проверка OHLCV:** порядок данных и единицы, `startTime` как открытие бара, сравнение с интервалом, исключение незакрытой свечи, последний ожидаемый закрытый бар, отсутствие дыр/дубликатов, полнота истории для периода/разогрева, корректность OHLC, метод/seed индикатора. **15m/1h/4h/1d — рекомендуемые, не принудительные для каждого вопроса**.

**Деривативы/события:** сравнение BTC и альткоина только по совместимым окнам; `openInterest` и `singleOpenInterest` нельзя смешивать; funding с единицей и интервалом; карты ликвидаций — модели, а не подтверждённые биржевые заявки; дата публикации новости отлична от даты индексации. Разбор Long/Short выражен как условная гипотеза с критериями отмены, не самостоятельный приказ на сделку.

Не объявлять это отдельным подтверждённым Node/CI прогоном в checkout или испытанием реального ChatGPT Skill runtime.

**Важно:** локальная модель свечей использует только **фиксированные минутные интервалы** и не проверяет календарные границы D/W/M; это прямое ограничение теста, при этом сам Skill требует реального биржевого календаря. Локальные вычисления индикаторов используют JS Number и одну конкретную seed-конвенцию, не эталон промышленной библиотеки и не proof of data authenticity. Тест не определяет доходность, реальный риск, ликвидацию или фактическую цену монеты.
