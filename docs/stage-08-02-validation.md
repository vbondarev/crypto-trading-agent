**MO01–MO24** — 24 документальных негативных ожидания: RT01/RT02; R1 без обязательной T02/P02; Bybit USDT Perpetual vs Spot/Last/Mark; HTTP 403; 15-минутная максимальная свежесть R1 и принудительный AD-009 recheck; user-provided screenshot; отсутствие `observed_at`; закрытые OHLCV; warm-up для EMA20; funding/OI/news/ликвидационные heatmaps; no readiness and no fabricated values; честная загрузка Skills.

Механические проверки в JS состоят из тестовых функций выбора маршрута, сверки идентичности и времени, баров и indicator warm-up, текстовых проверок фактического Markdown и targeted in-memory mutations. **MO01–MO24 не являются 24 независимыми ответами LLM**, а арифметический PASS скрипта не доказывает ни Bybit API, ни качество будущего анализа.
