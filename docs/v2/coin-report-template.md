# Crypto Trading Agent v2 — Coin Profile and bot proposal response template (NOT ACTIVE)

This is a user-facing **optional sections** template; it is not a source of market data, a verified live report or permission to trade.

## 1. Scope and freshness
Pair/exchange/market type; `as_of` time and last verified market observation; confidence and coverage (COMPLETE_FOR_SCOPE/PARTIAL/INSUFFICIENT).

## 2. Market regime
BTC/ETH direction, BTC dominance, sector context, macro catalysts. For each important factual claim give dated source/evidence ID; disclose missing context.

## 3. Project and social/news context
Confirmed coin-specific announcements and tokenomics/unlocks, X and Telegram primary posts where **actually accessible**, independent reporting, rumors and disagreement. Mark unobserved sources `ACCESS_UNAVAILABLE`; no fabricated sentiment counts.

## 4. Technical and derivatives picture
Global trend (4h/1d if available); local trend (15m/1h if available); OHLCV/indicator periods, EMA/RSI/ATR/MACD only when valid, levels, invalidation; OI, funding and estimated liquidation areas labeled with source and limits.

## 6. Trading interpretation
Recommendation: LONG / SHORT / WAIT; alternatives, why; confidence not a profit probability. Explain **trend ≠ trade**.

## 7. Veles or GinArea proposal (only if requested and platform selected)
Specify mode, IN/OUT, grid/range, order amount and unit, entry/exit rules, costs and reserves using **actual evidence-backed** P01/P02 fields. Include `risk_screen`, missing proof, `DRAFT|NEEDS_DATA|NOT_RECOMMENDED|VERIFIED_FOR_MANUAL_REVIEW` with exact reasons. If known hard risk breach, state REJECTED and omit executable grid; final only with verified form and full relevant portfolio. Never claim placed order.

## 8. Missing data and next action
One most important missing fact or user selection if any, plus concrete changes requiring AD-009 RECHECK. Do not demand private full T02 for informational research.
