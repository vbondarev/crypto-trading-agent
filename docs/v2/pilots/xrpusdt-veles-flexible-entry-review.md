# Проверка гибких индикаторов Veles DCA на XRPUSDT

Проверка выполнена 23.11.2026 в текущем сеансе Codex по обновлённым инструкциям. Использованы зафиксированные публичные свечи Bybit и синтетические контроли. Python воспроизводит логику стратегии. Метки в редакторе и бэктест Veles не проверялись. ## Запрос для повтора

> Разбери условия входа Long в Veles DCA для Bybit XRPUSDT Perpetual через «Гибкие индикаторы». Сначала должна закрыться свеча 4ч выше 1,0257 USDT. Затем на закрытой свече 1ч минимум касается уровня или проходит ниже, а закрытие остаётся выше. Если после пробоя и до ретеста 1ч закрывается на уровне или ниже, сценарий сбрасывается. Покажи, какие части можно выразить в Veles, и проверь их на историческом срезе из примера простых индикаторов.

Исторический срез **23.11.2026, 21:02:02 МСК**. Свеча 4ч закрылась в **19:00** на **0,9921** с максимумом **1,0257**. Свеча 1ч закрылась в **21:00** на **0,9571** с минимумом **0,9538**. Закрытие 4ч ниже уровня, поэтому рыночный статус на срезе — **`WAIT`**, настройка к запуску — **`NOT_RECOMMENDED`**. [Входные данные](xrpusdt-veles-simple-entry-review.md#запрос-для-повтора)

## Сопоставление с конструктором

Ниже приведены строки для проверки выразимости правила. Уровень `L` — исторический ориентир из запроса. Значения в таблице не образуют настройки для запуска.

| Проверка | Аргумент 1 | Оператор | Аргумент 2 |
|---|---|---|---|
| Закрытие выше уровня | Candle, Close, 4ч, по закрытию, сдвиг 0 | Больше | Константа `L`, USDT |
| Минимум ретеста на уровне или ниже | Candle, Low, 1ч, по закрытию, сдвиг 0 | Меньше | Константа `L + tick`, USDT, при подтверждённых сетке цен и точности |
| Закрытие ретеста выше уровня | Candle, Close, 1ч, по закрытию, сдвиг 0 | Больше | Константа `L`, USDT |

Для второй строки в офлайн-примере использован шаг **0,0001 USDT**. При `L = 1,0257` строгий порог **1,0258** включает точное касание 1,0257 и исключает цену на один шаг выше. Для редактора это отображение требует проверки точности константы и ценовой сетки используемого ряда. [Операторы Veles](https://help.veles.finance/ru/platform/settings/flexible-indicators/#операторы-сравнения) · [Candle](https://help.veles.finance/ru/filters/candle/) · [Константа](https://help.veles.finance/ru/filters/constant/) · [Шаг цены Bybit](https://bybit-exchange.github.io/docs/v5/market/instrument)

Все три строки в группе **И** проверяют совпадение условий. Для точной стратегии дополнительно нужно дождаться свечи 1ч, начавшейся после закрытия 4ч или на его границе. Её закрытие должно наступить строго позже. Между пробоем и ретестом закрытие 1ч на уровне или ниже отменяет ожидание. Первое подтверждение завершает эту попытку. Срок ожидания применяется только там, где он задан. Описание Veles подтверждает отдельные сравнения и чтение прошлых свечей через сдвиг. Срабатывание всей последовательности с фиксацией момента пробоя и сбросом остаётся неподтверждённым. До появления такой проверки агент предлагает вручную сверять последовательность закрытых свечей. [Логика групп Veles](https://help.veles.finance/ru/platform/settings/flexible-indicators/#как-работает) · [Раннее наблюдение редактора](stage-09-portfolio-risk-verification.md#проверка-конструктора-гибких-индикаторов)

## Результат офлайн-сравнения

В Python проверено **11 из 11** случаев на десятичных ценах. За исключением исторического ряда, это синтетические контроли с моментом закрытия пробойной свечи **19:00**. «Совпадение» в таблице означает истинность трёх сравнений без проверки порядка и сброса. Это модель упрощённой логики, а не наблюдение поведения Veles при выравнивании таймфреймов.

| Случай | Совпадение | Последовательное правило |
|---|---|---|
| Исторический срез, 4ч закрылась на 0,9921 | Нет | `WAIT` |
| 4ч закрылась ровно на уровне | Нет | `WAIT` |
| Похожая свеча 1ч закрылась до пробоя 4ч | Да при таком сопоставлении | `WAIT` |
| Свечи 1ч и 4ч закрылись в 19:00. Low 1ч 1,0230, Close 1ч и 4ч 1,0330 | Да | `WAIT` |
| В 20:00 ретестная свеча ещё не закрылась | Нет при расчёте по закрытию | `WAIT` |
| Поздняя 1ч закрылась выше, её Low 1,0258 | Нет | `WAIT` |
| В 20:00 Low 1ч 1,0257 и Close 1,0310 после Close 4ч 1,0330 | Да | Подтверждён ценовой сигнал |
| В 20:00 Close 1ч на уровне, в 21:00 появляется ретест | Да на второй 1ч | Сброс уже произошёл |
| В 20:00 Close 1ч ниже уровня, в 21:00 появляется ретест | Да на второй 1ч | Сброс уже произошёл |
| Ретест 1ч подтвердился в 21:00 при заданном сроке до 20:00 | Да | Срок истёк |
| После первого валидного ретеста следующая 1ч снова удовлетворяет двум сравнениям | Да в обоих случаях | Сигнал только на первом ретесте |

Для проверки непосредственно в Veles сопоставь время меток входа в предпросмотре или бэктесте с такими же эталонными случаями. В особенности проверь общую границу свечей, точность цены касания, сброс и повторный сигнал. Факт появления нужных полей или успешный синтетический прогон не подтверждают эти метки.
