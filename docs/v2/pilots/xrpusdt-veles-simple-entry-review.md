# Проверка разбора условий входа Veles DCA на XRPUSDT

Проверка выполнена 23.11.2026 в текущем сеансе Codex с обновлённым навыком конфигурации, адаптером Veles и новым справочником. Для сценария использовано историческое наблюдение публичного Bybit API. Проверка оценивает ответ агента и отдельно воспроизведённое ценовое правило. В редакторе Veles сигнал не тестировался. [Навык конфигурации](../../../.agents/skills/bot-configuration/SKILL.md) · [Адаптер](../adapters/veles.md) · [Справочник](../../reference/veles-dca-simple-indicators.md)

## Запрос для повтора

> Veles DCA, Bybit XRPUSDT Perpetual, направление Long. В «Условиях открытия сделки» выбраны «Простые индикаторы». Хочу открываться после закрытия 4ч выше 1,0257 USDT и последующего ретеста на закрытой свече 1ч. На ретесте минимум должен коснуться уровня или уйти ниже, а закрытие остаться строго выше. Закрытие 1ч на уровне или ниже после пробоя сбрасывает сценарий. Проверь готовый «Умеренный» набор и возможность добавить подходящие фильтры вручную. Используй исторический срез ниже. Разбери только условия входа.

Время отсечения Bybit — **23.11.2026, 21:02:02 МСК**. Закрытая свеча 4ч в **19:00** имела максимум **1,0257** и закрытие **0,9921**. Закрытая свеча 1ч в **21:00** имела минимум **0,9538** и закрытие **0,9571**. Свеча 4ч, заканчивающаяся в 23:00, на срезе ещё формировалась. [Время сервера Bybit](https://bybit-exchange.github.io/docs/v5/market/time) · [Свечи Bybit](https://bybit-exchange.github.io/docs/v5/market/kline)

## Результат прогона агента

1. **Вкладка и набор.** Разбор ведётся внутри «Условия открытия сделки → Простые индикаторы». «Умеренный» — готовый набор входных фильтров. Его состав, таймфреймы и пороги не приведены в прочитанной справке, поэтому соответствие заданному сценарию не установлено. Параметры ордеров не влияют на этот вывод.
2. **Рыночное условие.** Решение на историческом срезе — **`WAIT`**. Четырёхчасовая свеча коснулась 1,0257 максимумом, но закрылась ниже. Часовую свечу нельзя засчитать как ретест после подтверждённого пробоя. Для запуска черновик остаётся **`NOT_RECOMMENDED`**.
3. **Ручные фильтры.** Документированный фильтр «Цена» сравнивает текущую цену с порогом раз в минуту. Он не доказывает закрытие 4ч. Совпавшие сигналы двух таймфреймов сами по себе не доказывают, что часовой ретест произошёл после закрытия 4ч и до сброса. Для такой последовательности точная настройка простыми фильтрами **не подтверждена**. По закрытым свечам можно проверить её вручную. Числовое условие запуска в Veles не предложено. [Фильтр «Цена»](https://help.veles.finance/ru/filters/price/) · [Порядок обработки фильтров](https://help.veles.finance/ru/filters/general/#порядок-обработки-нескольких-фильтров)

## Контрольные случаи

Ценовое правило отдельно воспроизведено в Python с десятичными ценами. Проверки прошли **7 из 7**. Кроме первого ряда, примеры синтетические.

| Случай | Результат проверки |
|---|---|
| Исторический срез XRPUSDT с закрытием 4ч 0,9921 | `WAIT` |
| Свеча 4ч закрылась ровно на 1,0257 | `WAIT` |
| Ретест 1ч случился до закрытия пробойной 4ч | `WAIT` |
| Ретестная 1ч ещё не закрылась | `WAIT` |
| Свеча 1ч закрылась выше уровня, но минимум не коснулся его | `WAIT` |
| Свеча 1ч закрылась ровно на 1,0257, затем возник похожий ретест | Сброс. Сначала требуется новый пробой |
| 4ч закрылась на 1,0330, затем 1ч показала минимум 1,0230 и закрылась на 1,0310 | Ценовое условие подтверждено. Риск и исполнение оцениваются отдельно |

Дополнительные проверки разбора по справке:

- **RSI и «Уровни RSI».** При RSI `28 → 29` условие «ниже 30» выполнено, восходящего пересечения нет. `28 → 31` даёт описанное в справке пересечение для Long, `72 → 68` — нисходящее пересечение уровня 70 для Short. [RSI](https://help.veles.finance/ru/filters/rsi/)
- **Разные таймфреймы.** В примере Veles сигнал 1ч в 13:00 и сигнал 5м в 13:25 совпадают по времени активности. Изменение порядка фильтров в списке не превращает их в последовательные шаги стратегии. [Фильтры](https://help.veles.finance/ru/filters/general/)
- **Обратный сигнал.** Для входа Long по Полосам Боллинджера справка связывает прямой сигнал с нижней границей, обратный — с верхней. [Обратный сигнал](https://help.veles.finance/ru/filters/general/#обратный-сигнал)
- **Условия выключены.** После закрытия сделки Veles может сразу открыть новую. Этот вариант не воспроизводит ожидание заданного пробоя и ретеста. [Настройки DCA](https://help.veles.finance/ru/platform/settings/full/#условия-открытия-сделки)
