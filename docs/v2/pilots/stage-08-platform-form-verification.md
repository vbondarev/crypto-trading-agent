# Этап 08 v2. Проверка форм Veles и GinArea PRO

Статус `IN_PROGRESS / VELES_P02_VERIFIED / GINAREA_P02_BLOCKED / NO_TRADE_READY`. Цель — подтвердить поля фактических редакторов для выбранного рынка и режима, чтобы агент мог точно сопоставлять параметры неисполняемого черновика с формой.

Основания: [этап 07](stage-07-bybit-public-data.md), [пять синтетических проверок](post-stage-07-synthetic-checks.md), [контракт P02](../../platforms/configuration-contract.md), [адаптер Veles](../adapters/veles.md) и [адаптер GinArea PRO](../adapters/ginarea.md).

| Шаг | Проверка | Критерий | Состояние |
| --- | --- | --- | --- |
| 08.1 | Сверить накопленные наблюдения по редакторам | Для каждого наблюдения указан рынок, режим, время, проверенный объём и открытые пробелы. | PASS |
| 08.2 | Зафиксировать P02 Veles «Простой» | Новый несохранённый редактор Bybit Futures / HYPEUSDT, выбранные направление и режим, видимые разделы и точные названия полей. Для применимых полей фиксируются показанные единицы, ограничения и условия видимости. | PASS для наблюдавшейся формы |
| 08.3 | Зафиксировать P02 GinArea PRO Default Grid | Селектор, рынок, пара и направление, применимые IN/OUT, сетка, стоп и контекст видимых полей. | Требуется вход в GinArea |
| 08.4 | Сверить черновик с P02 | Каждое сопоставление проверяемо по выбранному режиму и свидетельству. Поля с отсутствующим доказательством помечены. Повторная проверка подтверждает блокировку финализации при недостающем T02 или риске. | Veles PASS, GinArea ожидает P02 |

## 08.1. Что уже подтверждено

- В [пилоте Veles](veles-simple-independent-replay.md#p02-and-pilot-status) 19.11.2026 около 20:32 МСК наблюдались четыре раскрывающихся поля в новом несохранённом редакторе Bybit Futures / HYPE/USDT / LONG / «Простой»: «Перекрытие», «Сетка ордеров», «% мартингейла» и «Отступ». В записи есть отображавшиеся единицы, варианты и диапазоны. Остальные разделы редактора и серверная валидация этой проверкой не покрыты.
- Для GinArea PRO в материалах этого пилота есть адаптер и синтетические сценарии. Подтверждённого наблюдения пользовательского редактора Default Grid для выбранной пары в просмотренных материалах нет.

## 08.2. Требования к наблюдению

Для Veles нужен снимок или запись экрана нового несохранённого редактора DCA с Bybit Futures, HYPE/USDT, направлением LONG и режимом ордеров «Простой». В кадре нужны выбранные рынок, пара, направление, режим и доступные разделы входа, сетки и выходов. Для длинной формы подходят последовательные снимки с перекрытием. Время наблюдения и версия редактора отмечаются при наличии. На снимках скрываются идентификаторы аккаунта, ключи и балансы. Проверка выполняется чтением формы без сохранения или запуска.

Этап относится к идентификации интерфейса. Проверка риска счёта, допуск к исполнению и подключение аккаунта остаются отдельными задачами.

## 08.2. Наблюдение Veles

20.11.2026 около 00:42 МСК открыт новый несохранённый редактор DCA с существующим подключением Bybit Futures. Подтверждены HYPE/USDT, LONG, режим ордеров «Простой» и режим тейк-профита «Простой». Номер версии редактора не установлен. Сведения относятся к отображаемой форме.

| Поле редактора | Отображение | Число вариантов |
| --- | --- | ---: |
| Перекрытие | 0,50–99% | 127 |
| Сетка ордеров | 2–60 ордеров | 59 |
| % мартингейла | 1–500% | 500 |
| Отступ | «Маркет» и 0,01–10% | 79 |
| Подтяжка сетки ордеров | 0,10–200% | 93 |
| Профит | 0,20–90% | 93 |
| Стоп-лосс | От −0,05% до −99%, список появляется после включения | 179 |

Диапазоны показывают крайние отображаемые варианты, между которыми шаг может меняться. В форме также наблюдались «Депозит», «Плечо», «Тип маржи», «Реинвест», «Условия открытия сделки», «Логарифмическое распределение цен», «Остановить бота после завершения сделок», «Валюта профита», «Стоп-лосс по сигналу» и «Остановить бота после исполнения стоп-лосса». Видимый диапазон плеча 1–75× описывает редактор. Ограничения проекта оцениваются отдельно. Условные поля альтернативных режимов, серверная валидация и биржевое исполнение не проверялись. Значения ордеров не вводились, бот не сохранялся.

## 08.3. Доступ GinArea PRO

Переход к редактору из текущего браузера открыл форму входа. Для завершения требуется авторизованная сессия GinArea либо снимки несохранённой формы с рынком, парой, направлением, выбранным Default Grid и видимыми секциями.

## 08.4. Проверка Veles

В офлайн-проверке использована штатная схема и валидатор ветки. Синтетический черновик `NEEDS_DATA` с семью точными названиями полей наблюдавшейся формы прошёл проверку. Значения полей ордеров оставлены пустыми. Попытка повысить статус до `VERIFIED_FOR_MANUAL_REVIEW` при наличии P02 и отсутствии T02 и подтверждения риска отклонена схемой и валидатором. Получены `RISK_UNVERIFIED`, `FINAL_VERIFICATION_NOT_ATTESTED` и `UNSUPPORTED_READY`. Исполнение недоступно. Часть GinArea ожидает 08.3.
