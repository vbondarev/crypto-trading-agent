Используется существующий [Python-сборщик](../../../tests/v2/pilots/collect_hype_r02_ohlcv.py) и новый [офлайн-повтор](../../../tests/v2/pilots/replay_hype_stage07.py) из коммита `5921e666d88a668cb9aeb24167d13357d8b1252d`.

| Проверка | Результат |
| --- | --- |
| Новый снимок | Запрос времени напрямую завершился тайм-аутом подключения. Браузер и веб-инструмент JSON не вернули. Автоматическая проверка заблокировала продолжение запуска при обнаружении стороннего запроса к эндпоинту телеметрии Visual Studio. Новый архив и манифест не получены. |

Время ответа тикера используется как приближение времени наблюдения отдельных полей. Окно 30 секунд заимствовано из сборщика для технической диагностики повторного анализа и не подменяет AD-009. Торговые свечи и Mark проверяются отдельно. Истечение интервала не доказывает финализацию биржей. ## Повтор проверки

Из корня репозитория передайте новому инструменту архив, созданный существующим сборщиком. По умолчанию свежесть оценивается относительно текущего времени. Для исторического воспроизведения используется явный UTC `--as-of`.

```powershell
python tests/v2/pilots/replay_hype_stage07.py $archive
python tests/v2/pilots/replay_hype_stage07.py $archive --as-of 2026-11-19T11:24:55.258Z
```

Свежий публичный архив остаётся необходимым для завершения этапа 07. Исторический повтор и контрольные копии не используются для оценки текущего рынка или торговли. Сырые снимки в репозиторий не добавлялись.
