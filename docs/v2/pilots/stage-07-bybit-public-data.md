## Повтор проверки

Из корня репозитория передайте новому инструменту архив, созданный существующим сборщиком. По умолчанию свежесть оценивается относительно текущего времени. Для исторического воспроизведения используется явный UTC `--as-of`.

```powershell
python tests/v2/pilots/replay_hype_stage07.py $archive
python tests/v2/pilots/replay_hype_stage07.py $archive --as-of 2026-11-19T11:24:55.258Z
```

Для завершения этапа 07 требуется свежий архив штатного коллектора, принятый штатным валидатором. Исторический повтор и контрольные копии не используются для оценки текущего рынка или торговли. Сырые снимки в репозиторий не добавлялись.
