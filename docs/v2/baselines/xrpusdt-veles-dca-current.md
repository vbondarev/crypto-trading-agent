# XRPUSDT — текущая базовая конфигурация Veles DCA

| Поле | Значение |
|---|---|
| Идентификатор версии | `XRPUSDT-VELES-DCA-2026-11-26-v1` |
| Дата фиксации | 26.11.2026, Europe/Moscow |
| Назначение | Текущая базовая версия для дальнейших сравнительных тестов |
| Основание | Конфигурация из чата, подтверждённая пользователем после исправления входа на Candle + EMA16/40 |
| Статус | `DRAFT` — сохранённая тестовая конфигурация, `NO_TRADE_READY` |
| Версия репозитория при фиксации | `94c11839fc5ce845bfd4dcc14e5c250ea70907f4` |

Этот файл фиксирует выбранные настройки. Он не подтверждает текущие настройки в кабинете Veles или состояние биржевого счёта. Для следующих тестов использовать именно вход с двумя фильтрами Candle и EMA16/40, описанный ниже.

## 1. Общие параметры

| Параметр | Значение |
|---|---|
| Платформа | Veles DCA |
| Биржа и рынок | Bybit USDT Perpetual |
| Торговая пара | XRPUSDT |
| Направление | Long |
| Плечо | **5×** |
| Базовый депозит бота в сохранённых тестах | **20,3677 USDT** |
| Номинал всей сетки до округлений | **101,8385 USDT** |
| Реинвестирование прибыли | **20%** |
| Общий тип индикаторов | **Гибкие индикаторы** |

Исходные вводные пользователя: выделенный бюджет **100 USDT**, планируемая торговля на **20 USDT** с плечом **5×**, дополнительно **200 USDT** портфельной маржи для просадок. В сохранённых тестах базовый депозит составляет **20,3677 USDT**; для воспроизведения использовать это значение, не заменяя его молча на 20 или 100 USDT. Бюджет 100 USDT и дополнительные 200 USDT не прибавляются к размеру сетки. Эти вводные не являются свежим снимком баланса или всего фьючерсного портфеля.

При реинвестировании объём следующих сеток увеличивается. В локальной модели реинвестируется 20% положительного результата закрытой сделки после торговых комиссий и до funding. После убыточной сделки расчётный бюджет бота автоматически не уменьшается; это допущение модели требует достаточного обеспечения.

## 2. Условия открытия сделки

Путь в Veles: **«Условия открытия сделки → Гибкие индикаторы»**.

Одна **«Группа 1»**, оба фильтра соединены **И**. Для всех четырёх аргументов: **12 часов**, метод **«По закрытию»**.

| Фильтр | Параметры первого аргумента | Оператор | Второй аргумент | Параметры второго аргумента |
|---|---|---|---|---|
| `Candle` | 12 часов; По закрытию; сдвиг **0**; источник **CLOSE** | **Больше** | `Candle` | 12 часов; По закрытию; сдвиг **1**; источник **HIGH** |
| `EMA` | 12 часов; По закрытию; период **16**; сдвиг **0** | **Меньше** | `EMA` | 12 часов; По закрытию; период **40**; сдвиг **0** |

Формула входа:

```text
Нет активной сделки
И Candle(12h, CLOSE, shift=0) > Candle(12h, HIGH, shift=1)
И EMA(12h, period=16, shift=0) < EMA(12h, period=40, shift=0)
```

Все значения берутся по закрытым свечам. EMA в локальном расчёте вычисляется по CLOSE. Оператор EMA — **«Меньше»**, не событие пересечения. При привязке 12-часовых свечей к UTC моменты проверки входа — 03:00 и 15:00 МСК.

В локальном тесте допускается одна активная сделка. Пока позиция занята, новые входы пропускаются. После закрытия бот ждёт следующего подходящего события на закрытии 12-часовой свечи.

## 3. Ордера сделки

Параметры сохранённой сетки для воспроизведения в режиме **«Простой»**. Значения задаются вручную; готовый пресет «Агрессивный», «Умеренный» или «Консервативный» не выбран этой спецификацией.

| Поле Veles | Значение |
|---|---|
| Режим торговли для воспроизведения сетки | **Простой** |
| Перекрытие | **2%** |
| Сетка ордеров | **4** |
| % Мартингейла | **1%** |
| Отступ первого ордера | **Маркет / 0%** |
| Логарифмическое распределение цен | **Выключено** |
| Подтяжка сетки ордеров | **0,1%** |

Расчётное распределение до биржевого округления:

| Ордер | Тип | Отступ от цены первого входа | Доля объёма всей сетки | Номинал при базовом депозите |
|---|---|---:|---:|---:|
| 1 | Рыночный | **0%** | **24,6281%** | ≈25,0809 USDT |
| 2 | Лимитный | **−0,6667%** | **24,8744%** | ≈25,3317 USDT |
| 3 | Лимитный | **−1,3333%** | **25,1231%** | ≈25,5850 USDT |
| 4 | Лимитный | **−2%** | **25,3744%** | ≈25,8409 USDT |

Для локального воспроизведения:

```text
N = 4
Цена уровня i = цена первого входа × (1 − 0.02 × i / 3), i = 0..3
Вес уровня i = 1.01^i
Номинал уровня i = депозит бота × 5 × вес i / сумму весов
```

Первый уровень исполняется по рынку; следующие цены округляются вниз по tickSize, количество XRP — вниз по qtyStep. Доли и номиналы в таблице являются расчётом модели, а не подтверждением фактически выставленных заявок. Значение подтяжки сохранено как 0,1%; в локальной модели при первом рыночном ордере она не применяется.

## 4. Выход из сделки

Путь в Veles: **«Выход из сделки → Тейк-профит → Сигнал → Гибкие индикаторы»**.

| Параметр | Значение |
|---|---|
| Режим тейк-профита | **Сигнал** |
| Проверка минимального P&L | **Включена** |
| Минимальный P&L | **0,7%** |
| Объём закрытия | **Вся позиция** |

Одна **«Группа 1»**, оба фильтра соединены **И**:

| Фильтр | Параметры первого аргумента | Оператор | Второй аргумент | Параметры второго аргумента |
|---|---|---|---|---|
| `Candle` | **5 минут**; По закрытию; сдвиг **0**; источник **CLOSE** | **Меньше** | `Parabolic SAR` | **5 минут**; По закрытию; сдвиг **0**; начало **0,02**, шаг **0,02**, максимум **0,2** |
| `Candle` | **15 минут**; По закрытию; сдвиг **0**; источник **CLOSE** | **Меньше** | `Candle` | **15 минут**; По закрытию; сдвиг **1**; источник **CLOSE** |

Формула прибыльного выхода:

```text
Candle(5m, CLOSE, shift=0) < Parabolic SAR(5m, 0.02, 0.02, 0.2, shift=0)
И Candle(15m, CLOSE, shift=0) < Candle(15m, CLOSE, shift=1)
И выполнен минимальный P&L 0.7%
```

В локальной модели условия проверяются на закрытии 5-минутной свечи с использованием последней закрытой 15-минутной свечи. Ценовой порог рассчитывается как `CLOSE / средняя цена позиции − 1 >= 0.007`. Фактическая трактовка P&L платформой отдельно не подтверждена этим файлом. Порог допускает выход; итоговая чистая прибыль зависит от рыночного исполнения, комиссий и funding.

После исполнения доборов средняя цена позиции пересчитывается. Выход закрывает всю позицию рыночным ордером. Частичная фиксация и фиксированный тейк 0,5% в эту базовую версию не входят.

## 5. Стоп-лосс

| Параметр | Значение |
|---|---|
| Тип | **Простой стоп-лосс по проценту** |
| Значение поля | **5%** |
| Активация | После исполнения **всех четырёх ордеров сетки** |
| Исполнение | Закрытие всей позиции по рынку |
| Дальнейшая работа в тестовой модели | Поиск следующего входа после закрытия сделки |

При перекрытии сетки **2%** и стопе **5%** уровень составляет приблизительно **7% ниже цены первого входа**:

```text
Цена стопа ≈ цена первого входа × (1 − 0.02 − 0.05)
           ≈ цена первого входа × 0.93
```

В локальном расчёте уровень округляется вниз по tickSize. Стоп действует независимо от SAR, CLOSE и минимального прибыльного P&L. Стоп по сигналу индикатора не задан этой версией. Рыночное исполнение может отличаться от уровня триггера.

## 6. Не зафиксированные параметры и границы

- Точное значение **частичного выставления ордеров** в форме не сохранено. Локальная модель допускает исполнение всех достигнутых последовательных лимитов внутри одной минуты; отдельно проверялось ограничение до одного лимитного исполнения за минуту.
- Фактический **режим маржи Bybit** не зафиксирован. Локальные тесты предполагали достаточную внешнюю Cross-маржу; это не подтверждает настройку реального счёта.
- Остальные переключатели кабинета, не перечисленные выше, не получают значений по умолчанию из этого файла. Фактическое поведение остановки бота после стопа в кабинете отдельно не подтверждено; продолжение поиска входов описывает сохранённую тестовую модель.
- Количество XRP и абсолютные цены ордеров не закреплены: они зависят от цены нового входа, текущего размера бота после реинвестирования и биржевого округления.
- Свежего полного снимка фьючерсного портфеля нет. Проверка готовности реального счёта к запуску этим сохранением не выполнялась.

## 7. Использование в следующих тестах

Эта версия является текущим эталоном: вход **12ч Candle CLOSE[0] > HIGH[1] И EMA16 < EMA40**, сетка **4 ордера / 2% / мартингейл 1%**, выход **SAR 5м И CLOSE 15м / минимальный P&L 0,7%**, стоп **5% после заполнения сетки**.

При сравнении новых гипотез явно указывать этот идентификатор и изменяемые параметры. Остальные настройки и допущения сохранять одинаковыми. Исходный вход без EMA считать отдельным историческим вариантом, а не текущей базовой версией. При принятии новой базовой версии фиксировать изменение и новый идентификатор, сохраняя историю предыдущей.

Метрики сравнительных тестов должны включать чистую прибыль, МПУ отдельной сделки, просадку капитала, количество закрытых сделок и открытые позиции с плавающим P&L на конец. Состав комиссий, funding, проскальзывание, период и реинвестирование указывать отдельно от настроек формы.
