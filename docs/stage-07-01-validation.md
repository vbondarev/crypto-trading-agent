## 1. Источники, входы и метод

Документы: [AGENTS.md](../AGENTS.md), [архитектура](architecture-decisions.md), [FR-001–FR-053](requirements.md), [AD-009 и R1/R2/R3](data-freshness.md), [MVP](mvp-scope.md), [проверка P01/P02](platforms/platform-validation.md), [контракт конфигурации 06.6](platforms/configuration-contract.md) и [итоговая приёмка 06](stage-06-review.md). Публичная [Agent Skills specification](https://agentskills.io/specification) просмотрена 16.10.2026: имена lower-case kebab-case ≤64, описание ≤1024, минимум YAML frontmatter + Markdown; дополнительные правила совместимой среды требуют отдельной проверки. Справка по спецификации **не является испытанием** обнаружения в обычном ChatGPT.

**Что действительно исполнено:** локальный JavaScript-модуль содержит чистые функции `validName`, `lintFrontmatter`, `router`, `labelAllowed`, `decision`, `loading`, `pathFromSkill`, `freshness` и 52 заранее заданных вызова с ожидаемыми результатами; при написании и перед фиксацией в GitHub выполнен тестовый прогон, **52/52 PASS**. Код позволяет повторение командой `node tests/stage-07-01-contract-synthetic.mjs` в корне клона нужной ветки. **Отдельный реальный Node.js/CI запуск на GitHub не проводился**; фактический прогон — JavaScript/V8 окружение инструмента с подстановкой `console` и `process`, не независимый ChatGPT blind-run.

**Границы:** `lintFrontmatter` — преднамеренно **лексическая предпроверка простого YAML**, а не полноценный YAML-парсер или официальный `skills-ref validate`. Обнаружив сложный block scalar, функция возвращает `NEEDS_FULL_YAML_PARSER`, а не выдуманное признание формата валидным/невалидным. `router` — **локальная нормативная модель желаемой маршрутизации**, не интерфейс/фактический движок обнаружения Skill. `labelAllowed` содержит короткий учебный словарь полей, **не** реальный P02.
